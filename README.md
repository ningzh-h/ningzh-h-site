# 种下大雪

一个用 **Astro + Markdown** 写的个人站点。

网站：<https://ningzh-h.github.io/ningzh-h-site/>

内容包括：

- 博客：文章、标签、归档、文件夹分组
- 笔记：多级目录、章节、右侧本页目录、PDF 导出
- 书影音：分类、文件夹分组、卡片 / 书籍视图
- 卡片：短文本集合
- 首页、关于页
