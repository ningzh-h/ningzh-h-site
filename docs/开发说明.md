# 开发说明

这份文档只给维护站点的人看，不是网站页面内容。

## 环境

- Node.js ≥ 22.23.4
- 依赖已写在 `package.json`，首次运行先安装：

```bash
npm install
```

## 本地启动

```bash
npm run dev
```

打开 <http://127.0.0.1:4321>。

Windows 下也可以双击 `start.bat` 或 `启动站点.bat`：首次会自动安装依赖，然后启动本地服务并打开浏览器。

## 目录

```
src/
├── site.config.ts        # 昵称、头像、导航、社交链接、列表页文案
├── content.config.ts     # 内容集合与 frontmatter 校验
├── content/
│   ├── blog/             # 博客
│   ├── notes/            # 笔记
│   ├── recreation/       # 书影音
│   ├── cards/            # 卡片
│   └── pages/            # 首页、关于页
├── layouts/              # 全站 / 博客 / 笔记 / 书影音布局
├── components/           # 顶栏、搜索、目录、卡片、首页区块
├── pages/                # 路由
├── lib/                  # 内容查询、分类、搜索、统计
├── plugins/              # Markdown 扩展插件
└── styles/               # 设计 token、全局样式、正文排版
docs/                     # 写作规范、设计说明、本文件
scripts/                  # 链接检查、PDF 导出、旧笔记导入、截图
public/                   # 头像、logo、图片
tests/e2e/                # Playwright 冒烟测试
```

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 本地开发（4321） |
| `npm run build` | 构建到 `dist/` |
| `npm run preview` | 预览构建产物 |
| `npm run check` | Astro + TypeScript 类型检查 |
| `npm run check:links` | 检查构建后的内部链接 |
| `npm run test:e2e` | Playwright 冒烟测试 |
| `npm run export:notes` | 把全部笔记导出为 PDF + zip 到 `exports/` |
| `npm run screenshots` | 截图到 `docs/screenshots/`（需先启动 dev） |
| `npm run import:note -- <源文件> <slug> --dry-run` | 导入旧笔记（先预览） |

## 草稿预览

```bash
# PowerShell
$env:SHOW_DRAFTS='1'; npm run dev

# bash
SHOW_DRAFTS=1 npm run dev
```

生产构建始终忽略这个开关。

## 依赖安装

项目根目录的 `.npmrc` 固定了：

- `legacy-peer-deps=true`
- `registry=https://registry.npmmirror.com`
- `replace-registry-host=always`

这样 npm 12 不会因为 lockfile 里的跨域名 tarball 报 `EALLOWREMOTE`。如果网络环境不同，改 `registry` 即可。

## 构建检查

```bash
npm run check
npm run build
npm run check:links
npm run test:e2e
```

构建产物在 `dist/`，是纯静态 HTML；`npm run preview` 只用于本地预览产物。
