# 种下大雪 · 站点设计说明

> 这是一个个人站点，用 Astro 生成静态页面，内容全部是 Markdown。
> 技术栈：Astro 7 + TypeScript + Markdown/KaTeX + 原生 CSS/JS。

---

## 1. 目标

- **Markdown 是唯一内容源**：博客、笔记、书影音、卡片、首页、关于页都是文件；
- **本地优先**：`npm run dev` 即可写作，不依赖后台和数据库；
- **内容与代码分离**：身份信息在 `src/site.config.ts`，正文在 `src/content/`；
- **长期可维护**：普通文件、Git 记录、纯静态产物，随时可以迁移。

---

## 2. 技术栈

| 依赖 | 用途 |
| --- | --- |
| `astro` | 静态站点生成、文件路由 |
| `@astrojs/markdown-remark` | unified 管线，保证 KaTeX / Shiki 行为可控 |
| `remark-math` + `rehype-katex` + `katex` | 数学公式 |
| `remark-directive` | `:::toggle` 折叠块语法 |
| `unist-util-visit` | 自定义 Markdown 插件 |
| `fuse.js` | 客户端模糊搜索 |
| `pinyin-pro` | 书影音标题的拼音首字母 |
| `@astrojs/rss` + `@astrojs/sitemap` | 订阅与站点地图 |
| `@playwright/test` + `jszip` | 冒烟测试、PDF 导出 |

## 3. 信息架构

```
/                       首页（content/pages/home.md + 自动区块）
├── /blog/              博客列表
│   ├── /blog/<slug>/   文章详情
│   ├── /blog/groups/   文件夹分组
│   ├── /blog/tags/     标签
│   └── /blog/archive/  归档
├── /notes/             笔记列表
│   ├── /notes/<path...>/           任意层级 index.md 入口
│   └── /notes/<path...>/<chapter>/  章节页
├── /shelf/             书影音分类入口
│   ├── /shelf/<category>/          分类页（卡片视图）
│   ├── /shelf/<category>/book/     分类页（书籍视图）
│   └── /shelf/<category>/<group...>/<slug>/  详情
├── /cards/             卡片墙
│   └── /cards/<path>/  卡片详情
├── /about/             关于页
├── /search-index.json  搜索索引
├── /rss.xml            订阅
├── /sitemap-index.xml  站点地图
└── /404                自定义 404
```

导航顺序在 `src/site.config.ts` 的 `nav` 里配置。

## 4. 内容模型

### 4.1 内容目录

```
src/content/
├── blog/           # 博客：一篇一个文件，可放子目录
├── notes/          # 笔记：目录树，index.md 是入口
├── recreation/     # 书影音：分类 + 文件夹分组
├── cards/          # 卡片：可平铺或子目录
└── pages/          # 首页、关于页
```

内容集合在 `src/content.config.ts` 中用 Zod 定义。字段写错时构建会指出文件和字段。

### 4.2 笔记树

- 顶层笔记目录必须有 `index.md`；
- 每个有 `index.md` 的子目录是一个入口页；
- 没有 `index.md` 的子目录是纯分组，可以继续展开；
- 目录下非 `index.md` 的 `.md` 是章节文件；
- 目录名保留在 URL 中，章节文件名的数字前缀只用于排序，不进 URL；
- 侧边栏默认展开 2 层（`NOTE_SIDEBAR_DEPTH`），可以继续展开更深的分组；
- 章节页右侧显示当前文件的 H2/H3 目录。

### 4.3 书影音

- `recreation/<分类>/index.md` 是分类介绍，不计数；
- 分类下可以直接放条目，也可以建 `01-xxx/` 文件夹分组；
- 文件夹名的数字前缀只用于排序，显示时去掉；
- 分组里也可以放 `index.md` 作为介绍；
- 有文件夹时按文件夹分组，没有文件夹时按首字母 A–Z；
- 详情 URL 支持任意层分组。

### 4.4 首页与关于

- `src/content/pages/home.md`：正文、`status`、`sections`、可选照片；
- `src/content/pages/about.md`：关于页正文；
- 昵称、头像、导航、社交链接、列表页文案在 `src/site.config.ts`；
- 首页 `sections`：`stats / notes / posts / cards / shelf`。

### 4.5 草稿

`draft: true` 默认在开发和构建中都不显示，不进列表、路由、搜索、RSS、sitemap。需要本地预览时：

```bash
SHOW_DRAFTS=1 npm run dev
```

生产构建始终忽略这个开关。草稿文件仍然在仓库里，不是加密。

## 5. 渲染与数据流

```
Markdown 文件
  → content.config.ts（glob 加载 + Zod 校验）
  → lib/content.ts / recreation.ts / cards.ts / pages.ts
  → 页面 getStaticPaths() 生成路由
  → render(entry) 得到 <Content /> 与 headings
  → 布局套壳
  → dist/ 静态 HTML + CSS + 少量 JS
```

### 5.1 路径

- `src/lib/url.ts` 的 `withBase()` 统一加 `BASE_PATH`；
- `rehype-base-url` 处理 Markdown 正文里的根路径链接和图片；
- 构建后用 `scripts/check-links.mjs` 检查断链。

### 5.2 Markdown 扩展

- `---` 是原生分隔线；
- `src/plugins/remark-toggle.mjs` 把 `:::toggle[标题]` 转成 `<details><summary>`，标题保留 Markdown 节点，公式和加粗都能渲染；
- `src/plugins/remark-relative-links.mjs` 解析相对 `.md` 链接，并兼容带空格的目标路径；
- `src/plugins/rehype-inline-markers.mjs` 把 `==高亮==` 转成 `<mark>`、`||剧透||` 转成 `<span class="spoiler">`；
- 插件跳过 `code/pre/math/annotation`，不破坏代码和公式。

### 5.3 搜索

- 构建时生成 `/search-index.json`，汇总博客、笔记、书影音、卡片；
- 首次打开搜索框才加载索引和 Fuse.js；
- 正文去 Markdown 标记后截断 1500 字。

### 5.4 导出

- 笔记页正文上方有「打印 / 保存 PDF」按钮；
- 打印样式隐藏导航、侧边栏、本页目录和按钮，并展开所有 `<details>`；
- `npm run export:notes` 把全部笔记打印成 PDF 并打包到 `exports/`。

## 6. 视觉与交互

- 系统中文字体栈，不加载网络字体；
- 正文 `17px / 1.8`，标题字重 650；
- 颜色主题：`pine`、`mist`、`clay`、`plum`、`ink`，与明暗模式独立；
- 首页：小头像 + 名字 + Markdown 正文 + 可选区块；
- 笔记：左侧可展开树 + 面包屑，右侧正文 + sticky 本页目录；
- 移动端：顶栏菜单、笔记目录抽屉、搜索对话框；
- 尊重 `prefers-reduced-motion`，提供跳过导航和可见焦点样式。

## 7. 本地开发

```bash
npm install
npm run dev
```

```bash
npm run check
npm run build
npm run check:links
npm run test:e2e
```

## 8. 隐私

这是一个公开静态站点。发布真实内容前确认：

- 不放真实姓名、学校、住址、邮箱、带定位的照片；
- 不放未授权的教材、课件、论文、付费内容；
- 图片有版权或来源说明；
- 草稿隐藏不是权限控制。
